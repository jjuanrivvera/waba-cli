## waba phone settings

Show the number's settings (incl. calling and SIP)

```
waba phone settings [phone-number-id] [flags]
```

### Examples

```
  waba phone settings
  waba phone settings --sip-credentials
```

### Options

```
  -h, --help              help for settings
      --sip-credentials   include the SIP password in the response
```
